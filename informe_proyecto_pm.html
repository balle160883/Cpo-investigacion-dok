1. Resumen Ejecutivo (Executive Summary)

El Sistema de Gestión de Investigaciones Domiciliarias CPO es una solución corporativa de misión crítica concebida para digitalizar, estructurar, georreferenciar y auditar de forma integral el levantamiento de estudios socioeconómicos para Solicitantes de Préstamo y Avales de Caja Popular Oblatos.

El proyecto resuelve la brecha operativa histórica existente entre la captura de solicitudes en sucursales bancarias dentro del core financiero SIF (SQL Server), el trabajo presencial de los investigadores de campo y la posterior deliberación crediticia por parte de los analistas en oficina matriz.

3. Blindaje Antifraude: Verificación satelital de coordenadas GPS al momento de la visita y registro inmutable en bitácora de auditoría.

2. Arquitectura Tecnológica y Componentes

El ecosistema opera mediante una arquitectura de microservicios contenerizada con Docker y Docker Compose en un servidor Dokploy de alta disponibilidad:

1
🏦 SQL Server SIF (Core)
Base de datos institucional (172.28.5.231:1433). Contiene los registros maestros de clientes, líneas de crédito y avales.
2
⚙️ Motor ETL Continuo
Procesos secuenciales cada 60s con estrategia UPSERT (ON CONFLICT DO UPDATE) que garantiza sincronización libre de duplicados.
3
🐘 PostgreSQL + Redis Cache
Motor transaccional central (31.97.144.6:5437) optimizado con JSONB para formularios dinámicos y Redis para aceleración web.
4
🚀 API RESTful + WebSockets
Node.js Express con Swagger UI (/api/docs), Socket.io para telemetría GPS y seguridad HTTP con Helmet/JWT.
5
💻 Web SPA & 📱 App Móvil
Frontend administrativo en React Vite con Mapbox GL y App Móvil en Expo / React Native para encuestadores de campo.

3. Matriz de Gobernanza, Roles y Permisos (RBAC)

Para salvaguardar el secreto bancario y la integridad crediticia, el sistema aplica el principio de menor privilegio (*Principle of Least Privilege*):

Rol del Sistema Perfil Institucional Permisos Clave Otorgados Restricciones Operativas
superadmin Dirección de TI / SysAdmin Control absoluto, gestión de usuarios, auditoría forense y configuración de entorno. Uso estrictamente restringido a personal técnico de infraestructura.
admin Jefatura de Crédito Gestión global de investigaciones, catálogos, mapas, estadísticas y exportación. No puede crear ni eliminar cuentas de usuarios del sistema.
asignador Coordinación de Campo Asignar y reasignar visitas a investigadores, monitoreo en mapa satelital. No dictamina créditos ni autoriza validaciones socioeconómicas.
validador Mesa de Control Validación de calidad, examen de fotos, aprobación de estudio, cancelación lógica exclusiva. Filtro previo indispensable antes de la entrega formal al analista de crédito.
coordinadora_analistas Norma Lizette Bermejo Palos Supervisión de expedientes validados, filtro múltiple por sucursales, asignación a analistas y mapa GPS. Visión gerencial de todo el lote validado; distribuye las cargas de trabajo.
analista Mesa Analítica de Crédito Revisión de capacidad de pago y dictamen final. Puede devolver el paquete al validador. Restricción estricta: solo ve los folios que le fueron asignados directamente.
investigador Encuestador de Campo Acceso exclusivo en App Móvil a su propia cola del día, captura offline/online y GPS. No tiene acceso a la plataforma web ni ve folios de otros investigadores.
auditor Auditoría / Cumplimiento Lectura de bitácora inmutable (*Audit Log*), métricas de productividad y SLA. Perfil 100% de solo lectura; sin permisos de edición ni aprobación.

4. Flujo Operativo y Ciclo de Vida del Crédito

El circuito operativo garantiza que ningún crédito se autorice sin que el 100% de las visitas del paquete (solicitante y avales) estén concluidas y validadas con evidencia física:

A
1. Captura en Sucursal
El socio solicita el crédito. Sucursal captura en SQL Server SIF. El motor ETL lo detecta en menos de 60 segundos.
B
2. Asignación a Campo
El Asignador ubica el domicilio en el mapa satelital y delega la orden al investigador asignado a esa zona geográfica.
C
3. Levantamiento en App
El encuestador arriba al sitio con Google Maps/Waze, captura fotos de fachada/interior, cuestionario y firma digital.
D
4. Mesa de Validación
El Validador examina el "Paquete Completado". Si cumple la calidad requerida, lo valida; de lo contrario, lo rechaza para solventar.
E
5. Asignación a Analista
Norma Bermejo supervisa el paquete validado y lo asigna al analista de crédito responsable de la sucursal de origen.
F
6. Dictamen y Desembolso
El analista revisa los ingresos vs egresos. Emite el dictamen final favorable que habilita a la sucursal a entregar los fondos.
Procedimiento Especial Ante Ausencia: Supuesto "Con Folio / Ticket de Cita" Si el socio no se encuentra en el domicilio al acudir el investigador, se implementó un protocolo formal: el investigador fotografía la fachada, expide el comprobante con la leyenda "FOLIO INVESTIGACIÓN: {id}" y clasifica la orden en espera. Esto previene gastos redundantes de combustible si el socio ya acudió a sucursal con previa cita.

5. Hitos Clave y Mejoras Recientes Entregadas

Durante el último ciclo de desarrollo se completaron con éxito requerimientos de alta prioridad técnica y operativa:

1. Erradicación de Deadlocks y Bloqueos en Base de Datos

Se solucionó un incidente crítico donde conexiones en estado idle in transaction con bloqueos exclusivos bloqueaban la app móvil y el portal web. Se reubicaron las sentencias estructurales a init_db.js y se configuró idle_in_transaction_session_timeout = '60s', logrando 100% de disponibilidad continua.

2. Gobernanza de Supervisión y Asignación de Analistas (Norma Bermejo)

Se eliminó la visibilidad global desordenada para los analistas de crédito. Cada analista únicamente ve sus folios asignados, mientras que la coordinadora Norma Bermejo cuenta con un módulo de distribución con multiselección por sucursal y acceso completo al Mapa Satelital GPS.

3. Mecanismo de Devolución de Paquete Completo

Se implementó la capacidad de devolver en un solo clic el paquete integral de investigaciones al validador cuando el analista detecta incongruencias en la capacidad de pago del titular o avales.

4. Filtro Inteligente de Paquetes Completados vs En Espera

La plataforma web ahora agrupa los créditos por paquete (titular + avales), señalando visualmente con distintivos verdes los créditos con 100% de visitas concluidas en campo para evitar revisiones a medias.

5. Blindaje de Cancelación Lógica (*Soft-Delete*)

Se prohibió el borrado físico de registros; solo el Validador de Crédito puede cancelar una investigación justificando el motivo en un modal obligatorio, quedando registrado de forma indeleble en auditoría.

6. Estandarización de Seguridad de Credenciales

Reseteo generalizado a estándar seguro corporativo (Seguridad2026@) con activación de la política de cambio obligatorio de contraseña en el primer inicio de sesión para todo el personal.
